# open-code-review-enhanced 1.0.2

发布日期：2026-09-23

## 变更明细

### 审查结果与会话面板

- 会话详情页展示审查失败的文件、失败原因和可直接执行的恢复命令。
- 对于分支范围和提交审查，提供恢复命令提示；工作区审查仍不支持恢复。
- 审查评论支持展示 `pending_confirmation`，让需要业务确认的结论与确定性问题清晰区分。

### 会话比较与导出

- 增加独立的会话比较 HTML 导出，导出结果自包含样式和脚本，离线打开也能使用。
- 增加 Markdown 比较结果导出，包含新增、持续、已解决和未重新审查的问题分组、数量和代码片段。
- 修复比较页面内容溢出，改善长路径、长文本和窄屏布局。

### 审查提示词、语言和工具

- 增强多语言指令解析，支持常见语言代码和名称，并要求解释性文本保持统一语言。
- 更新审查提示词，明确待确认事项、建议代码和逐文件审查要求。
- 工具 schema 要求提供非空建议代码和待确认字段；JSON 参数修复、结果模型、文本及 SARIF 输出同步保留待确认信息。

### 安装与 CI

- Linux/macOS 平台包安装后强制校验并修复二进制可执行权限。
- GitHub Actions 行内评论及汇总输出保留待确认信息。
- 主包与 Linux、macOS、Windows 的 x64/arm64 平台包统一升级并重新打包为 `1.0.2`。

## 升级

```sh
npm install -g open-code-review-enhanced@1.0.2 --allow-scripts=open-code-review-enhanced
```

## 兼容性与来源

基于 `feat/review-dashboard-integrated`，对比 `v1.0.1` 整理。内置中文背景提示词仍需显式启用；默认命令不会自动加载它。

发布准备使用 OpenAI Codex（GPT-6）。
